# parquet-backend — read-side query backend over Parquet (Prometheus/Tempo/Loki + SQL)

The founding workspace of the querier: serves the Prometheus, Loki, and Tempo query APIs plus cross-signal SQL over the gateway's Parquet store via DataFusion — including catalog/table discovery, PromQL lowering (instant + range, rate/`*_over_time`/histogram_quantile/topk), LogQL and TraceQL mapping, query cache, telemetry, standalone compactor (sealed-day sort-merge, provenance footers, retention GC), query-frontend day-sharding, metric rollup tiers, and full demo integration (compose services, datasources, `$datasource`-switched dashboards).
