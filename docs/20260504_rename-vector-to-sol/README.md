# rename-vector-to-sol

This project is a fork of Datadog Vector, licensed under MPL-2.0. As described in MARKET.md Section 20, **"Vector" is a trademark of Datadog / Timber Technologies** and the fork must be renamed before any public release or marketing. The chosen name is **Sol** (**S**ingle **O**bservability **L**ayer).
